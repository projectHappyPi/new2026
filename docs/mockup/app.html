튼튼이 · 앱 전체 목업

한 손으로 3초, 엄마·아빠가 같이 보는 육아 기록

실제 앱과 같은 색·배치·규칙으로 만든 클릭 목업이에요. 버튼을 짧게 누르면 바로 저장, 길게(마우스는 오른쪽 클릭) 누르면 상세 입력이 열려요. 기록하면 오른쪽 위젯과 달력이 같이 바뀌고, “아빠 폰에서” 버튼으로 가족 공유 동기화도 볼 수 있어요.

아빠 폰(Galaxy)에서

동기화 대기 · 30초마다
  • —아빠 폰에서 기록하면 서버를 거쳐 이 폰의 타임라인·달력·위젯에 나타나요.

기록

  • 엄지 궤적: 오른손 기준 피벗에서 반지름 128·216, 각도 100·141·181°에 6개 버튼
  • 분유·기저귀·이유식은 탭 한 번에 저장, 수면·모유는 시작/종료
  • 확인 창 없이 저장하고 5초 되돌리기

달력 · 가족 공유

  • 일정에 작성자(나/아빠)가 붙고 상대 폰에도 떠요
  • 30초마다 + 기록 직후 동기화, 마지막 수정이 이김
  • 설정 › 가족 공유에 서버 주소·가족 코드·내 이름

위젯

  • iPhone: 작게·중간·잠금화면 상태 위젯 + 크게 달력 위젯
  • Galaxy: 2×2 상태(“48:14 전” 표기) + 4×4 달력
  • 설정 › 위젯에서 항목·다음 수유 계산·배경 선택
